# 後加工工賃 工程別・工場間比較 月トレンド

検証スキル（`kouchin-consistency-check`）とは別。①③突合は行わない。

## 目的（UXの主軸）

- **特定工程**を抜き出し、国分と湖南を同じグラフで比較する
- 「湖南↓・国分↑」のような **振替・シフト疑い** を一覧する（断定しない）
- 全工程スパゲッティ折れ線は出さない（付録は表のみ）

## データ源（②のみ）

| 工場 | 参照 |
|------|------|
| 国分 | 次の2フォルダを直接参照（`.lnk` は使わない）。同一年月が複数あれば**更新日時が新しいファイル**を採用 |
| 湖南 | `KONAN_SHISAN_ROOT`（湖南共有 `2 後加工試算`）。`.lnk` は読まず絶対パス |

国分の参照先（`common.KOKUBU_MEISAI_DIRS`）:

- `\\192.168.0.101\共有フォルダ\国分工場\国分管理\後加工\後加工工賃明細\工賃明細2026年度（令和8年度）`
- `\\192.168.0.101\共有フォルダ\国分工場\国分管理\後加工\後加工工賃明細\工賃明細２０２５年度　(R7年度)`

対象ファイル名: `*後加工工賃明細*.xls*`（年月はファイル名の「yyyy年m月度」）

## 実行

```bash
python .cursor/skills/kouchin-monthly-trend/scripts/trend_kouchin.py
python .cursor/skills/kouchin-monthly-trend/scripts/trend_kouchin.py --months 6
```

依存: `python-calamine`, `openpyxl`（国分フォルダ走査に `pywin32` は不要）

## 出力シート

| 順 | シート | 役割 |
|----|--------|------|
| 1 | **サマリ** | 30秒判断: 合計・前月差・振替疑いTop・注目工程・ナビ（加工量は km 単位） |
| 2 | **工程比較** | 注目工程ごと 国分(赤茶)/湖南(若草) の2系列（加工量[km]＋加工賃[千円]、太線＋丸マーカー、値のみラベル、凡例右） |
| 3 | **負荷シフト** | 前月差一覧・判定（強い相殺/弱い相殺/同方向、加工量は km 単位） |
| 4〜 | **付録_*** | 全工程表・シート区分（深掘り用、グラフなし） |

工程グループ: 国分の「スライス1/3」は「スライス」に合算して湖南と比較。
単位: 加工量は元データ（m）→ **km**、加工賃は元データ（円）→ **千円**（いずれも四捨五入で整数）。

## エージェント手順

1. スクリプトを実行する
2. 出力パスと警告を伝える
3. サマリの振替疑いTopと、工程比較の注目工程を短く要約する
