# 依頼書入力「受注検索」タブ設計

日付: 2026-09-07  
状態: 設計承認済み（実装前レビュー待ち）

## 目的

依頼書入力に、受注ファイル行を **閲覧・参照** するための検索サブタブを追加する。  
過去の製品／投入原反の実績を、納期範囲とキーワードで素早く見つける。

編集フォームへの遷移・転記は対象外。

## 要件（確定）

| 項目 | 内容 |
|------|------|
| 主目的 | 閲覧・参照（編集ジャンプなし） |
| データ | 一括照合と同じ、読込済み受注行のみ |
| 納期 | **希望納期** または **調整納期** のいずれかが範囲内ならヒット（両方が空の行は非ヒット） |
| 納期範囲 | 検索時に必須（From / To） |
| 製品・原反 | 部分一致の **OR**。少なくとも一方は必須（両方空は拒否） |
| 条件組み合わせ | 納期条件 AND（製品 OR 原反） |
| UI | 左条件パネル / 右結果テーブル |
| タブ名 | 受注検索 |
| 並び | 一括照合 → 目次シート → **受注検索** → 【設定】 → 後加工商品マスタ → マスター一覧 |

## アーキテクチャ

```
ReconciliationApp
  └─ Tab「受注検索」
       └─ JuchuOrderSearchPane  (UI)
            └─ JuchuOrderSearch.filter(records, criteria)  (純関数)
                 └─ JuchuOrderSearchCriteria
```

- `ReconciliationApp`: タブ登録、読込済みレコードの供給、再読込後の一覧更新フック。
- `JuchuOrderSearchPane`: DatePicker×2、製品名／投入原反 TextField、検索ボタン、結果 TableView、件数ラベル。
- `JuchuOrderSearch` / `JuchuOrderSearchCriteria`: UI 非依存。単体テストの主対象。

巨大な `ReconciliationApp` への業務ロジック追記は最小限にする。

## フィールド対応（受注 db キー）

| UI | db キー | 判定 |
|----|---------|------|
| 納期 From〜To | `希望納期`, `調整納期` | どちらかが `[From, To]`（両端含む）に入る |
| 製品名 | `製品` | 改行区切り複数行を結合し部分一致（大文字小文字は既存正規化に合わせる） |
| 投入原反 | `品名1`, `原反品名` | いずれかに部分一致 |
| 結果列 | 依頼No / 希望納期 / 調整納期 / 製品 / 原反（表示用に品名1優先） / ユーザー / 入力日 | — |

日付パースは既存の受注日付解釈（`parseLocalDate` 相当）に揃える。解釈不能な納期は「そのキーではヒットしない」。

## バリデーション・メッセージ

1. From または To が未指定 → 検索せず「納期範囲を指定してください」
2. From > To → 検索せず「開始日が終了日より後です」
3. 製品名・投入原反が両方空 → 検索せず「製品名または投入原反を入力してください」
4. 0 件 → 表を空にし「0 件」を表示

## タブ管理

- `MainShellInnerTabCatalog.labelsFor(REQUEST_FORM_INPUT)` に「受注検索」を目次シートの次へ追加。
- 子タブ内に追加の TabPane / TitledPane は置かない（`nestedInnerTabLabels` / `titledPaneLabels` の変更不要）。

## テスト計画

`JuchuOrderSearchTest`（案）:

- 希望納期のみ範囲内 → ヒット
- 調整納期のみ範囲内 → ヒット
- どちらも範囲外 → 非ヒット
- 製品のみ一致 → ヒット（原反空）
- 原反のみ一致 → ヒット（製品空）
- どちらも不一致 → 非ヒット
- 条件不足（納期欠落 / キーワード両方空）→ 呼び出し側バリデーション、または filter 前に拒否
- 部分一致（部分文字列）
- 日付解釈不能行は納期条件で非ヒット

## 対象外（YAGNI）

- 一括照合フォームへの選択ジャンプ
- 依頼書原本フォルダ横断検索
- 結果の Excel エクスポート
- 後加工商品マスタ参照検索の流用
- 入力日・ファイル更新日時での絞り込み

## 実装時の注意

- 日本語文字列は UTF-8 リテラル（`\uXXXX` 禁止）
- `code_java` は Maven（`mvnw.cmd`）
- 依頼書原本フォルダへは書き込まない（本機能は受注行の読取のみ）
