# 加工トレンド Excel 固定フォルダ出力

## 目的

加工トレンドタブの Excel 出力で保存ダイアログを廃止し、ローカル固定フォルダへ書き出す。最新1件のみ残し、ツールバーから開く。

## 仕様

| 項目 | 内容 |
|------|------|
| 出力先 | `{repo}/.pm-ai-cache/exports/processing-trend/` |
| ファイル名 | 日時付き（既存 `suggestFileName`） |
| 旧ファイル | 出力直前に同フォルダ内の `*.xlsx` を全削除 |
| 保存ダイアログ | なし |
| 開く | ツールバー「Excelを開く」→ フォルダ内最新 `.xlsx` |
| 完了 UI | 短い通知（パス表示）。モーダルの「開く」は不要 |

## 非対象

集計・シート構成・環境変数での出力先変更。
