設計 4/4 — エラー処理・テスト・完了条件

この節で設計レビューは完了です

エラー・境界

  • 読込時ファイル無し → baseline = ABSENT。保存時にファイルが出現していれば競合
  • 保存直前にファイル消失 → 競合扱い（要約: ディスク上に無い）。上書きで新規作成可
  • ハッシュ計算失敗（権限・I/O） → 保存中止 + エラーダイアログ（上書き強制は出さない）
  • 要約生成失敗 → ダイアログは出し、要約欄は「詳細差分を生成できませんでした」+ ファイル名・ハッシュ先頭
  • 「上書き」選択後に書込失敗 → 既存の保存エラー処理。baseline は更新しない

テスト

  • 単体: Fingerprint（同一／変更／欠落）、Guard（単一・セット）、代表 Summarizer 数種
  • 結合: 一時ファイルを外部改変して保存 → ダイアログ分岐（再読込／上書き／キャンセル）

完了条件

  • 明示保存対象画面すべてが Guard 経由
  • 各画面に業務語 Summarizer（Gemini 資格情報は秘匿要約）
  • ダイアログ UI は強調ヘッダ + スクロール要約（案 B）
  • 常時ファイルロックは導入しない
