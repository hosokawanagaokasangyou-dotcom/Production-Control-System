設計 2/4 — コンポーネントと対象画面

共通 API と、明示保存がある画面一覧

共通（新規）

  • FileContentFingerprint — パス → SHA-256（欠落は sentinel）
  • SaveConflictGuard — baseline と現ファイルの比較、セット判定
  • ConflictDiffSummarizer — 画面別プラグイン interface
  • ConflictSaveDialog — 業務語要約 + 3 ボタン

対象画面（明示保存）と関連ファイル

  • 会社カレンダー / メンバー勤怠 → attendance-data.json + 勤怠・機械カレンダー.xlsx
  • 機械カレンダー → machine-calendar-data.json + 同 xlsx
  • 配台マスタ → master-dispatch-sheets.json + master.xlsm
  • 配台計画（タスク入力） → PM_AI_PLAN_INPUT_PATH
  • 配台不要ルール → exclude rules JSON
  • 特別ルール（JSON / ビルダー / 工程優先） → special rules JSON
  • 材料・製品種類 → サマリ同フォルダの .txt 群
  • 設備ガント担当保存 → 計画 JSON + 契約 JSON（+ 関連 xlsx 同期時）
  • 依頼書入力（設定 JSON / 受注転記 / 後加工マスタアップロード xlsx）
  • ユーザープロファイル / グローバル設定パッケージ既定
  • 環境変数・Gemini 資格情報暗号化（中身は秘匿、有無・更新のみ要約）

対象外

  • session-state.json 等の自動保存
  • 列順・バッジ等の UI 微調整自動永続
  • 操作者ユーザー bin の即時永続（別途必要なら後続）

同一ファイルを複数タブが触る場合

例: 会社カレンダーとメンバー勤怠は同じ JSON。各タブが独自 baseline を持つ。片方で保存成功したら、他タブは次回保存時に競合扱い → 再読込を促す（意図どおり）。
